\section{Problem and design motivation}
We study multi-view 3D editing from one edited target RGB image and three
undeformed source RGB images with calibrated cameras. The target specifies a
geometric edit, while the sources provide complementary appearance evidence.
Unchanged spatial projection can associate a source feature with an incorrect
location after deformation. Semantic retrieval offers an alternative, but a
single retrieved correspondence can be unreliable, and a better correspondence
score does not by itself establish an improvement in the generated asset.

We investigate a source-adaptation path that preserves the pretrained
multi-view conditioning function at initialization. The design separates
candidate retrieval, candidate aggregation, ray-based feature delivery, and
retargeting. This separation permits matched comparisons of individual choices
and prevents a gain from one component from being attributed to another.

\subsection{Pretrained multi-view carrier and ray groups}
Let $T$ be the native target feature map, $S_j$ the native feature map of source
view $j\in\{1,2,3\}$, and $P_j$ its calibrated projection into the SS conditioning
grid. We retain the original four-view carrier $C_{\mathrm{MV4}}$, including
its native target contribution and global-conditioning tokens. For a source
camera and image patch $p$, define a ray group
\begin{equation}
 \mathcal R_{j,p}=\{x:\pi_j(x)=p\}.
\end{equation}
Voxels assigned to this camera ray share an image-space evidence decision.
Native bilinear projection distributes the resulting map to the grid. This is
different from predicting an independent attention output for each voxel.
The grouping is determined by the input cameras; it does not require a target
surface depth or a surface-visibility test at inference.
In the supplied SS implementation, grouping uses a $16^3$ conditioning grid
and a $32\times32$ patch map per source view; SS64 refers to the decoded
occupancy resolution.

\subsection{Semantic proposals and member-preserving matching}
For each observed target patch $m$, raw semantic similarity retrieves an
initial set of $K=64$ source patches across the three source images. A frozen
matching decoder contextualizes the target descriptor, and its score head
produces a categorical distribution $p_m(k)$ on these proposals. We separately
evaluate raw semantic descriptors, learned contextual descriptors, and use of
the scalar matching score; these are distinct design choices.
D1 denotes the frozen trained contextual matching decoder used in this study.
It contains one query-only cross-attention block with four heads of width 32,
a 128-dimensional feed-forward bottleneck, and gated residual updates;
candidate descriptors remain unchanged. A LayerNorm--MLP scalar head with
hidden width 64 adds a bounded $0.25\tanh$ residual to the contextual cosine
score. At feature aggregation time, scores use a fixed softmax temperature
of 0.05. Matching keys are 1024-dimensional layer-12 FRAME Omega descriptors;
the SS values are distinct, 1024-dimensional native DINOv3 features.

\paragraph{Matcher supervision and training.}
Offline supervision maps an edited-surface point to the undeformed mesh
through their shared vertex topology and barycentric coordinates. Source
projection and a z-buffer check with depth tolerance 0.005 provide the valid
positive patch IDs $\mathcal P_m$ for target patch $m$. For its raw 64-proposal
set $\mathcal C_m$, only queries with a positive in the proposal set contribute
to the listwise loss
\begin{equation}
 \ell_m=-\log\frac{\sum_{k\in\mathcal C_m\cap\mathcal P_m}\exp s_{mk}}
                         {\sum_{k\in\mathcal C_m}\exp s_{mk}}.
\end{equation}
We average eligible-query losses within each asset; assets without an
eligible query do not update the matcher. Proposal misses and unobservable
queries are recorded separately, rather than assigned an invented positive.
The RGB matcher uses 9,143 certified training examples and all 508 validation
examples. Six teacher-rejected training cases are excluded only from matcher
training; the SS population remains 9,149. AdamW uses learning rate $10^{-4}$,
weight decay 0.01, and gradient-norm clipping at 1. The fixed final checkpoint
after seven passes contains 62,545 optimizer updates; it is not a
validation-best epoch selection. The matching backbone remains frozen while
this head is trained, and the complete matcher is frozen during subsequent
generative fine-tuning. Topology and depth labels are supervision only, never
inference conditioning or a surface-visibility write mask.

One source-camera ray may intersect grid sites assigned to different target
patches. Let $\mathcal M_r$ contain the distinct observed target patches of ray
$r$. The member-based candidate construction averages their normalized
distributions before retaining a final $K$-element support:
\begin{equation}
 \bar p_r(k)=\frac{1}{|\mathcal M_r|}\sum_{m\in\mathcal M_r}p_m(k),\qquad
 p_r(k)=\frac{\bar p_r(k)}{\sum_{l\in\mathcal K_r}\bar p_r(l)},\quad k\in\mathcal K_r.
\end{equation}
Here $\mathcal K_r=\operatorname{TopK}(\bar p_r)$; missing entries in an
individual member distribution have zero mass. Duplicate occurrences of the
same target patch vote once. This retains complementary candidate modes
before the final truncation, rather than matching one averaged descriptor.
The observation support uses input image alpha and camera addresses. It is
not an inferred surface-visibility mask.
Empty observed-member sets or fewer than 64 valid source patches abstain,
retaining native conditioning rather than inventing proposal values.

\subsection{Matching-aware evidence aggregation}
The fixed-evidence candidate aggregates original source values $v_k$ as
\begin{equation}
 E_r=\sum_{k\in\mathcal K_r}p_r(k)v_k.
\end{equation}
The value features retain their native magnitude. The same evidence is used
by the carrier update, source-use decision, and retargeter. Thus matching
weights influence attention without requiring an additional learned value or
output projection.

We also evaluate a learned refinement with four heads and identity values.
For head $h$, the learned score difference is anchored to its initial score:
\begin{equation}
 a_{rhk}=\operatorname{softmax}_{k\in\mathcal K_r}
 [\log p_r(k)+s_{rhk}(\theta)-s_{rhk}(\theta_0)],\qquad
 E_r=\sum_k\left(\frac14\sum_h a_{rhk}\right)v_k.
\end{equation}
The implementation centers the score difference by its prior-weighted mean,
which does not change the softmax. Zero prior support remains zero. This
initializes the learned candidate to exactly the fixed matching distribution.
Additional learned refinement is a tested option, not a prerequisite assumed
by the method description. Comparisons with learned value/output transforms
are reported separately.

\subsection{Source contrast retargeting and native fallback}
Let $u_r$ be a learned source-use probability and $g$ a signed, bounded fusion
gate. The retargeter receives the displacement between retrieved evidence and
the source feature already present in the native carrier, together with
target context:
\begin{equation}
 R_r=R_\phi([E_r-S_r,\,T_r]),\qquad
 \Delta_r=u_r\{g(E_r-S_r)+R_r\}.
\end{equation}
Here $T_r$ pools native target context over the grid sites of ray $r$;
the observed distinct members determine the matching posterior, rather than
restricting this native-context pool.
The resulting SS conditioning is
\begin{equation}
 C=C_{\mathrm{MV4}}+\frac14\sum_{j=1}^3P_j(\Delta_j).
\end{equation}
Subtracting $S_r$ is appropriate here because that feature is present in
$C_{\mathrm{MV4}}$. It would not be appropriate for a target-only carrier.
At initialization, $g=0$ and the retargeter output is zero, restoring the
native conditioning function. Rays without matching evidence contribute zero
correction and retain the native multi-view prior. This fallback does not
write a zero-valued observation into the source feature map.

The target feature extraction and its direct conditioning path are retained.
The source branch is the only adapted image-conditioning path. This structural
property does not guarantee exact target RGB preservation by the generated
asset, which remains an empirical evaluation question. No extra
surface-visibility write mask is introduced.

\subsection{Stage composition}
SS64 and PBR1024 continue the supplied multi-view LoRA checkpoints and their
matching configurations. Shape512 and Shape1024 remain frozen. The matching
backbone and decoder are frozen during these generative fine-tuning runs.
PBR retargeting is compared with vanilla PBR on identical generated geometry,
archived native guides, texture sampling noise, and rendering triangles.
The PBR feature-correction candidates are distinct from the SS identity-value
aggregation above; no shared positive effect across stages is presumed.

\section{Experimental protocol}
\subsection{Data and initialization}
Deformation fine-tuning uses the constructed DeformNeXt-10k split, with 9,149
SS training examples, 508 validation examples, and 508 test examples. PBR
training uses 9,139 examples after the recorded training-only exclusion of ten
oversized cases. Source-asset identities are disjoint across these deformation
splits. This does not establish disjointness from the earlier multi-view
pretraining data. The mixed385 subset (80,892 training assets and 950 validation
assets) describes that earlier multi-view fine-tuning, not the deformation
fine-tuning population.

The supplied multi-view checkpoints are SS64 step 4,210 and PBR1024 step
16,850. Both frozen base weights and LoRA weights are loaded using their
original configurations. The frozen shape checkpoints are Shape512 step
4,210 and Shape1024 step 16,850. The matching backbone uses the selected
VGGT-Omega epoch-7 checkpoint. Exact weight and input identities are retained
in the experimental records.

SS comparisons use 480 optimizer updates with global batch 96, LoRA rank and
alpha 16, denoiser learning rate $10^{-5}$, and conditioner learning rate
$10^{-4}$. PBR comparisons use 1,900 updates with global batch 24, denoiser
learning rate $5\times10^{-6}$, and conditioner learning rate $10^{-4}$.
These budgets correspond to approximately five passes through their respective
training populations. Ablation inputs, initialization, budget, sampler, and
evaluation pairing are held fixed. Removed components are physically absent;
absent channels are not replaced by zero placeholders.

\subsection{Development, independent confirmation, and final test}
The SS development panel contains 128 examples from 93 source-asset clusters,
evaluated using three paired generation-noise seeds and 12 sampling steps.
Both the 32-example and 128-example development panels are subsets of the
508-example validation split. They are disjoint from the final test split in
sample identity, source UID, and source-asset cluster; the test split contains
134 source-asset clusters. This separation is verified from the manifests,
without accessing held-out predictions or quality measurements.
Generation-noise repetitions are averaged within an example before inference
over source clusters. They are not independent training seeds. The completed
main SS ablation results use training seed 101. A completed, separate seed202
study evaluates vanilla, the Top-1 semantic-matching/retargeting branch, and
Fixed evidence under the same three-noise protocol. A separate two-seed PBR
training diagnostic is also complete; its four fixed-shape examples do not
constitute an inferential quality or full-pipeline confirmation.
Rendering development uses an initial fixed 32-example panel and a completed
paired 128-example expansion, each with one generation-noise realization.

PBR training trends additionally use four fixed target-camera examples with
GT shape conditioning. Within each training seed, compared models and all
epochs must share exactly the same rendered GT pixels. Across independent
training seeds, RGB, camera, noise, GT latents, and cold predicted latents
remain exact; rendering is checked against the producer's previously declared
bounded initial-render policy. Each seed retains its own rendered reference
and metrics, without pooling these curves as a common-pixel quality estimate.
This small stage diagnostic does not establish source preservation or
generated-geometry performance. The joint-cascade evaluation retains its
common rendered-GT requirement.

For the working Fixed seed101 checkpoint, two fresh saved-model loads on
36 validation examples reproduce all archived prediction/target latent and
occupancy arrays. The check verifies 72 archive files, the original
32-example reference prefix, and the final batch of four under native
batch size eight, without optimizer updates. This establishes SS replay
and tail-batch consistency, not rendered quality or final pipeline selection.

Final model choice uses both geometric alignment and source preservation,
rather than SS IoU alone. Required validation fresh-load/cache checks,
independent-training confirmation, model selection, and protocol freezing
precede evaluation on all 508 test examples. The final table compares
source-only zero-shot, edited-target zero-shot, vanilla fine-tuning,
retargeting, and the selected combined model when it is distinct. Source-only
zero-shot uses four undeformed M0 RGB views, including the original target
camera. Edited-target input uses M1 RGB at camera 8 and M0 RGB at cameras
9, 10, and 11.

\subsection{Metrics and statistical scope}
Source appearance is evaluated by VGG-based LPIPS~\cite{zhang2018lpips} and
the official DreamSim ensemble~\cite{fu2023dreamsim} at cameras 9 and 10.
Image--image cosine similarity from a separate original OpenAI CLIP
ViT-B/16 encoder~\cite{radford2021clip} is a complementary semantic measure;
it is not a text--image caption score. References preserve the
original material identity on the edited M1 geometry; they are not undeformed
M0 RGB images. Target alignment is evaluated by PSNR, SSIM~\cite{wang2004ssim}, and 2D alpha-mask
IoU at camera 8, together with Chamfer distance and surface F-Score in 3D.
Surface evaluation uses 20,000 points and F-Score threshold 0.02 in the fixed
normalized frame, without a result-specific ICP alignment. Voxel IoU is an SS
diagnostic and is not substituted for these mesh/rendering endpoints.

More precisely, for area-weighted surface point samples $A$ and $B$, we use
$d(a,B)=\min_{b\in B}\lVert a-b\rVert_2$ and
\begin{equation}
 \mathrm{CD}(A,B)=\frac12\left[\frac1{|A|}\sum_{a\in A}d(a,B)
 +\frac1{|B|}\sum_{b\in B}d(b,A)\right].
\end{equation}
We report this symmetric, unsquared Euclidean CD. Surface F-Score is the harmonic mean of
the fractions of points within $\tau=0.02$ of the opposite surface, with zero
assigned when both fractions are zero~\cite{tatarchenko2019surface}.
Our declared sampling count and threshold are specific to this protocol.
Mask IoU thresholds both rendered alpha maps at 0.5. Pixel and VGG metrics
use archived float RGB with nominal unit range; SSIM uses an 11-pixel
Gaussian window with standard deviation 1.5. The pinned DreamSim, CLIP, and
Inception paths convert RGB to rounded, clamped 8-bit images before their
respective official preprocessing. Full-frame scores are primary;
GT-only foreground crops are supplementary.

FID~\cite{heusel2017fid} and KID~\cite{binkowski2018kid} assess the global rendered-image distribution using the full
prescribed final panel. They are not per-asset scores. The finite-sample KID
estimate is reported with its sign. Official DreamSim/CLIP and Inception evaluation
uses FP32 with TF32 and autocast disabled. All models use the same reference,
camera, rendering, and image preprocessing protocols. Cameras 8--10 are input
camera evaluations; these results are not evidence of novel-view performance.
The final pool contains 1,524 images per model (508 assets at three cameras),
using the same-count original-material reference pool. Pinned
torch-fidelity 0.3.0 reduces 2,048-dimensional Inception features in
float64; KID uses 100 subsets of 1,000 images with seed 42017. Its subset
standard deviation is not a source-cluster confidence interval. Distribution
values are descriptive under this renderer and reference population, rather
than a human-study result or a per-asset significance test.

Paired uncertainty estimates resample source-asset clusters, retaining the
dependence between deformations of an asset and between generation noises.
The original finite ablation family and the subsequent evidence follow-up
are reported as separate studies. The DEV32 intervals in this draft are
exploratory and unadjusted; they are not final test confirmation. Primary
geometry endpoints are CD/F-Score, and primary appearance endpoints are
LPIPS/DreamSim. Positive CLIP results do not change that priority after the fact.
Main scalar means weight deformation examples equally after averaging the
two source cameras where applicable; equal-source means are also retained.
The final contract includes the eight pairwise endpoints in the selected
model's comparisons with V1 and retargeting, omitting a self-comparison if
selection merges models. Its primary family size is $8C$ for $C$ such
contrasts, with Bonferroni-adjusted source-cluster bootstrap intervals.
Descriptive input/baseline contrasts remain separate. An interval containing
zero is not evidence of equivalence or non-inferiority. Independent training
confirmation is reported separately from uncertainty conditional on the main
checkpoint and generation protocol.

The completed SS training-confirmation study uses 4,000 paired source-cluster
draws for three contrasts: Top-1 minus vanilla, Fixed minus vanilla, and
Fixed minus Top-1. Each training seed and the mean of the two fixed trained
checkpoints use this three-contrast IoU family separately. The intervals do
not form a simultaneous nine-comparison interval or estimate uncertainty
over a population of training seeds. They remain development evidence,
distinct from the module-ablation and held-out families below.

For the pending final Fixed-context development study, we predeclare six
contrasts: the three adjacent matching-ladder differences, Fixed versus
actual Top-1, Fixed versus Uniform-K, and Fixed versus physical retargeter
removal. Across the eight camera-role endpoints above, these define a
48-comparison family. Its planned Bonferroni percentile intervals use 48,000
source-cluster bootstrap draws; unadjusted development intervals are retained
separately. This family is distinct from the final held-out $8C$ family.
These controls have not yet produced downstream results.
The completed stage evaluations give macro IoU 0.473613 for Uniform-K,
0.473471 for Fixed, and 0.468832 for physical retargeter removal on the
same DEV128 and three noises. These descriptive estimates support further
evaluation of retargeting but do not establish a score-weighting advantage,
equivalence, or full-cascade benefit. The complete six-contrast stage family
and the new downstream measurements remain pending.
SS diagnostics use the same six contrasts as a separate primary voxel-IoU
family, after averaging three noises within each asset. Precision, recall and
voxel F1 are retained as secondary diagnostics. Global occupancy ratios are
reported separately from macro per-asset means. Joining these diagnostics
to the cascade table requires the same checkpoint bytes and exact noise-zero
SS records, while preserving the different three-noise and one-noise scopes.

\subsection{Evidence-utilization analysis}
To connect retrieval with its use, we observed the trained fixed and
learned conditioners on the same 32 development assets used by the cascade
and correspondence diagnostics. All 64 native conditioning forwards completed.
Native batch-eight conditioning was retained, and the observer reproduced
the unobserved conditioning tensors exactly. Topology label arrays were opened
only after the corresponding paired model forwards finished.
We measured exact-match probability mass on ray--target-patch relations
whose prior Top-1 is incorrect but whose retained Top-K contains a match,
together with source-use probability and the magnitude of the actual source
map correction. Inputs, candidate addresses, and frozen priors matched
between models. Per-asset observations were joined to existing geometry and
source-render measurements; such associations are not causal interventions.
Uniform-K mass is a diagnostic reference and does not replace the separately
matched Uniform-K training ablation.

The native observation population contains 50,516 observable relations.
Its addresses were reproduced by the GPU BF16 projection used during native
conditioning; the historical CPU FP32 diagnostic has a different population
because projection rounding changes patch addresses. We preserve both scopes
and do not silently substitute one denominator for the other. Among the
31,408 native relations with a wrong prior Top-1 but a match in Top-K,
exact-match mass is 1.6266\% for uniform weighting, 6.4601\% for the fixed
matching prior, and 6.1756\% for learned attention. The learned-minus-fixed
change is $-0.2844$ percentage points, with an exploratory unadjusted
source-cluster interval of $[-0.9776,0.4890]$ percentage points. The learned
head changes probabilities, but additional exact-match mass is not established.
The prior's larger mass than uniform supports its use of candidate evidence;
it does not establish generated-quality improvement over a matched uniform
model. Exact patch correspondence also does not capture every potentially
useful semantic candidate.

generated asset. The observed member IDs are distinguished from the full

\paragraph{Candidate coverage versus generated quality.}
The reused CPU FP32 matching diagnostic contains 50,493 observable
source-camera-ray/target-patch relations from 32 development source clusters.
On the same raw 64-candidate support, exact relation coverage at rank one
increases from 1.25\% for raw cosine to 7.73\% for the contextual D1 descriptor

CPU candidate-core parity was checked separately; native GPU projection

For the member proposals, 31,393 relations have a wrong Top-1 but a GT match

\section{Discussion and limitations}
\paragraph{Retrieval, aggregation, and adaptation are separate hypotheses.}
Higher candidate coverage establishes that useful evidence is available;
probability mass on those candidates measures how it is allocated. Neither
observation establishes that the adapted conditioning improves a generated
asset. The completed same-support Uniform-K comparison tests this distinction
directly at the SS stage, and its adjusted interval does not establish a
weighting advantage. The original member and ray controls likewise do not
establish independent quality gains. These findings favor evaluating each
choice in the final delivery path rather than treating retrieval diagnostics
or membership in a strong pipeline as proof of necessity. They also do not
identify extra learned projections as the cause of earlier failures: the
original and shared-evidence architectures differ in multiple respects.

\paragraph{Alignment and preservation must be read jointly.}
The paired DEV128 cascade gives Fixed a positive exploratory surface F-Score
difference from Top-1, while source LPIPS and DreamSim have worse point
estimates. This is a geometric improvement signal with unresolved appearance
cost, not evidence of uniform superiority. Source references retain the
original material on edited geometry, so preservation here concerns
appearance after deformation rather than equality to undeformed source
pixels. We retain both endpoint groups in model selection and reporting;
an interval containing zero does not certify preservation or equivalence.
The final held-out comparison must establish which improvements survive
the frozen pipeline and protocol.

The original twelve-model, ten-module-contrast family and paired DEV128
cascade extension are complete. Final-context matching controls, downstream
ablations, and held-out results remain pending. The separate two-seed PBR
training diagnostic is complete but does not establish pipeline quality.
The completed two-seed SS study supports the combined branches relative to
vanilla; it does not isolate each component or establish cascade generalization.
Geometric improvement
does not ensure source appearance improvement. Preserving the direct target
stream does not guarantee unchanged target output. Input-alpha support is not
surface visibility, and the source-use gate is not a calibrated occlusion
predictor. The final abstract, concluding superiority claims, quantitative
contribution statements, and final model label must follow these experiments.
