\section{Supplementary evidence and reproducibility}
This Supplement retains complete development studies and their limits. It
does not reinterpret exploratory results as held-out confirmation.

\subsection{Architecture, matcher and training details}
D1 has one query-only cross-attention block with four heads of width 32 and
a 128-dimensional feed-forward bottleneck. Candidate descriptors are unchanged.
A LayerNorm--MLP scalar head of hidden width 64 adds a bounded
$0.25\tanh$ residual to contextual cosine. The listwise objective averages
eligible queries within an asset; assets without an eligible query do not
update the matcher. The final seven-pass checkpoint contains 62,545 updates,
using AdamW rate $10^{-4}$, weight decay 0.01 and gradient clipping 1. Six
teacher-rejected cases affect matcher training only; the SS population is
still 9,149. No test matching-head training or calibration is performed.

The selected SS uses identity values and no new learned readout. An evaluated
alternative anchors learned logit refinement to its initial score:
\begin{equation}
 a_{rhk}=\operatorname{softmax}_{k\in\mathcal K_r}
 [\log p_r(k)+s_{rhk}(\theta)-s_{rhk}(\theta_0)].
\end{equation}
Four-head probabilities average before native value aggregation. Prior-weighted
centering of the score difference preserves this softmax, and zero prior
support remains zero. This initialization reproduces Fixed weights, but an
initialization safeguard is not evidence of a quality advantage. Learned
V/output transforms are distinct alternatives. Absent deformation-query
channels and source modules are physically removed in their respective
controls.

The original SS/PBR base and frozen matcher tensors, LoRA initialization,
per-rank input/noise/timestep traces, and saved checkpoint/config hashes are
verified in the experimental artifacts. Main SS comparisons use a native
microbatch 96 without accumulation; native PBR uses four ranks with
microbatch 6, accumulation 1 and global batch 24. Shape stages, image encoders,
Omega and the matching decoder remain frozen during generative fine-tuning.

\subsection{Metric implementation details}
Let $A,B$ be the two sets of 20,000 area-weighted surface samples and
$d(a,B)=\min_{b\in B}\lVert a-b\rVert_2$. The reported unsquared distance is
\begin{equation}
 \mathrm{CD}=\tfrac12\left[|A|^{-1}\sum_{a\in A}d(a,B)
                  +|B|^{-1}\sum_{b\in B}d(b,A)\right].
\end{equation}
Precision is the fraction of $A$ with distance at most 0.02 to $B$;
recall reverses the roles. Surface F-Score is their harmonic mean, or zero
when both fractions vanish. The source-defined normalization and stored GT
point sample are common to models; there is no independent output alignment.

Photometric scores use the archived 512-pixel float RGB and nominal unit
range. Native PSNR is $-10\log_{10}\mathrm{MSE}$ over the full image;
VGG LPIPS receives the affine normalization from $[0,1]$ to $[-1,1]$.
SSIM uses an 11-pixel Gaussian window, standard deviation 1.5 and the native
zero padding. Mask IoU thresholds both alpha maps at 0.5.

DreamSim uses the official trained ensemble; complementary CLIP uses a
separate original OpenAI ViT-B/16 image encoder. Their paths clamp RGB to
$[0,1]$, round to nearest 8-bit RGB, and apply their respective official
preprocessing. Inception receives the same full-frame 8-bit conversion.
Neural metric evaluation uses FP32, TF32 off and no autocast. Source scores
average cameras 9/10 within an example; camera 11 conditions generation but
is not added to the scored pool. Target scores use camera 8.

Supplementary foreground PSNR uses the union of predicted and GT alpha
masks above 0.5. It averages RGB squared error only on that union and clamps
the resulting MSE below at $10^{-12}$ before taking the logarithm. This is
not a common GT-only mask. The separate GT crop is the GT-alpha bounding box
with padding $\lceil0.1\max(w,h)\rceil$, clipped to the image boundary;
the identical box crops prediction and reference for every model. It can
retain background inside the rectangle and does not align or recenter
individual predictions.

The edited GT mesh is rasterized independently. After a post-TEST GT-only
audit of all 1,524 views, the one-pixel-dilated raster gate permits at most
$\lceil0.01N_{\mathrm{GT}\alpha}\rceil$ outside pixels. The original
continuous 0.99 containment gate rejected one thin-object view (7/648
outside pixels; containment 0.9891975); the uniform integer rule admits all
views. The failed run is retained. Only this admission gate was adapted in
rendering and case validation; GT, predictions, metric formulas and frozen
model selection are unchanged. The gate is not a score.

\subsection{Execution and reproducibility scope}
All 5 fixed pipelines use 508 test examples from 134 source clusters and one
prescribed generation noise per example. Global occupancy ratios are
distinguished from mean per-asset IoU. All 2,540 SS archives are checked for
actual latent hashes, packed occupancy and TP/FP/FN consistency; occupancy is
not substituted for surface CD/F-Score or appearance metrics. Generated
geometry is not aligned independently per output. PBR comparisons retaining
the same geometry use identical original guide values/order/scale and
rendering triangles.

The test campaign bounds complete-asset disk credits. Local raw and fully
consumed guide duplicates are offloaded only after producer/reader checks
and fresh canonical file-server hashes. Scored pixels and provenance remain
local, and canonical intermediate archives remain on the file server.
Completed native cases from a stopped campaign retain their original paths,
model/noise bindings, terminal records and scored-image identities; remaining
cases use the same frozen numerical protocol. Protected readers cause waits,
and retirement transactions do not signal GPU workers. Recovery changes
scheduling and cache lifecycle, without choosing models from test scores or
altering metric endpoints.
The final metric and qualitative artifacts retain actual producer/file hashes
and the original model-freeze/declaration lineage.
