\begin{abstract}
Recent image-to-3D models generate high-quality assets,
but modifying geometry while preserving its
identity remains challenging.
%
A key difficulty is that the target geometry and original
source views depict different shapes, making
direct feature fusion unreliable.
%
We present GEAR3D, a geometry-conditioned
image-to-3D framework that leverages VLM-guided editing
to establish a geometry-aligned target view and
appearance retargeting to adapt source evidence
according to the deformed target view.
%
By selectively adapting source features within
projection-based conditioning, GEAR3D preserves
original appearance while following the intended geometry.
%
We further introduce DeformNeXt-10k, a paired
deformation dataset with surface correspondences and multi-view observations.
%
Experiments demonstrate a favorable balance between source appearance
preservation and target alignment, enabling flexible and high-fidelity 3D
editing.
\end{abstract}
